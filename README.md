# Thursday 19 November 2026 — The World in One Day

An entry for make.fun `news-image-20261119`: one image summing up the
world news of Thursday 19 November 2026.

`main.py` (Python 3.13, standard library only, no network) draws the
infographic and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `./out/entry.png`). The output is deterministic: two runs write
byte-identical PNG files.

## The six stories

1. **GTA VI rolls out worldwide** — gamers enter Vice City after a
   13-year wait (Reuters / AP).
2. **Trump, Xi and Putin meet** — first three-way summit in Shenzhen
   at APEC (Reuters).
3. **Voyager 1 one light-day out** — NASA confirms the probe is
   16 billion miles away (NASA).
4. **Cyclone Akvan nears India** — storm heads for the coast between
   Machilipatnam and Puri (The Hindu).
5. **Islam to top world faiths** — Pew: Muslims the largest religion
   by 2035 (NDTV).
6. **Earth's lost billion years** — study: ice and mantle erased
   ancient rocks (Space.com).

## Run

```sh
python3 main.py
```
